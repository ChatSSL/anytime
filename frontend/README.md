# Anytime 웹앱 (프론트엔드)

공강이 겹치는 같은 학교 학생과 열린 모임을 추천하는 캠퍼스 매칭 플랫폼의 프론트엔드입니다.
인공지능융합플랫폼 팀 프로젝트(챗송심이) 제안서와 Figma 프롬프트(M0~S15) 기준으로 만들었고, 백엔드 없이 목업 데이터로 끝까지 동작합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
```

Node 18 이상. 라우터는 HashRouter라서 정적 호스팅에 그대로 올릴 수 있습니다.
상태는 브라우저 localStorage(`anytime-state`)에 저장되고, 마이페이지의 "로그아웃 · 처음부터 다시"로 초기화됩니다.

## 화면과 경로

| 프롬프트 | 화면 | 경로 |
|---|---|---|
| S1 | 스플래시, 온보딩 3장 | `/welcome` |
| S2 | 학교 이메일, 인증번호, 인증 완료 | `/auth`, `/auth/code`, `/auth/done` |
| S3 | 프로필(닉네임, 학과, 관심 활동) | `/profile` |
| S4 | 시간표 입력, 공강 자동 산출 | `/timetable/setup`, `/me/timetable` |
| S5 | 홈(다음 공강, 모임, 추천 사람, 타임라인) | `/home` |
| S6 | 추천 사람 상세, 1:1 요청 | `/person/:id` |
| S7 | 열린 모임 목록, 필터 | `/rooms` |
| S8 | 모임방 상세, 합류, 취소 | `/rooms/:id` |
| S9 | 모임방 만들기 | `/rooms/new` |
| S10 | 채팅(모임방, 1:1), AI 대화 주제·미션, 오픈채팅 링크 대체 | `/chats`, `/chat/:id` |
| S11 | 취소 규칙, 일정 변경, 마감, 인원 미달 자동 취소 | 모임방 상세 안에서 처리 |
| S12 | 출석 확인, 상호 평가 | `/review/:roomId` |
| S13 | 마이페이지, 매너 점수 기준, 공개 범위 | `/me`, `/me/manner`, `/me/privacy` |
| S14 | 신고, 차단, 긴급 신고, 제재 안내 | 어느 화면에서나 시트로 열림, `/me/sanction` |
| S15 | 알림 센터, 알림 설정 | `/notifications`, `/notifications/settings` |
| S16 | 로딩, 빈 화면, 오류 상태 모음 | `/states` |
| S17 | 데스크톱 레이아웃(사이드바, 2열, 분할 보기) | 1024px 이상에서 자동 |
| S18 | 광고 배너, 프리미엄, 쿠폰(확장 예정) | `/premium` |

## 시연 팁

- 이메일 인증은 백엔드(`localhost:8080`)가 켜져 있어야 합니다. 학교는 단국대학교만 됩니다. 로컬에서 메일 설정이 없으면 인증번호가 백엔드 로그에 `[개발 모드] ... 인증번호: 123456`으로 찍힙니다.
- 시간표 단계에서 "예시 시간표로 둘러보기"를 누르면 바로 공강 계산을 볼 수 있습니다.
- 마이페이지 아래 "시연 시간 이동"으로 지금 시각을 바꿉니다. 수업 중 홈, 마감 임박, 인원 미달 자동 취소 화면을 이걸로 확인합니다.
- 모임방 상세의 "시연: 방장이 시간을 30분 늦춰요"로 일정 변경 알림과 재확인 흐름을 볼 수 있습니다.
- 채팅에서 메시지를 보내면 상대가 잠깐 뒤에 답합니다(시연용).

## 구조

```
src/
  types.ts            데이터 타입
  data.ts             목업 사용자·모임·시간표, 초기 상태
  store.tsx           전역 상태(Context)와 모든 동작(합류, 취소, 신고 등)
  lib/time.ts         공강 계산, 시간 겹침, 충돌 검사 (규칙 기반)
  lib/ai.ts           취향 유사도, 대화 주제·미션 (AI 자리)
  lib/derive.ts       추천, 모임 상태(모집 중·마감·취소), 매너 라벨
  components/ui.tsx   버튼·칩·모임 카드·사람 카드·시간표 등 공통 컴포넌트
  components/safety.tsx  신고·차단·긴급 신고
  screens/            화면별 파일
  styles.css          디자인 토큰(M1)과 전체 스타일, 다크 모드 포함
```

디자인 토큰은 `styles.css` 맨 위 `:root`에 있습니다. 라임색(`--free`)은 공강 표시에만 씁니다.

## 백엔드로 바꿀 때

제안서 역할 분담대로 아래 지점만 교체하면 됩니다.

| 지금 | 교체 대상 |
|---|---|
| `AuthCode`의 OTP 검사 | Spring Boot 인증 API(학교 메일 SMTP, OTP, JWT) |
| `store.tsx`의 동작 함수 | 각 REST 호출. 함수 이름과 인자는 그대로 둘 수 있음 |
| `lib/derive.ts`의 `recommendPeople`, `recommendRooms` | 서버 추천 API. 공강 겹침 계산은 서버에서만 하고 겹치는 시간대만 내려받기 |
| `lib/ai.ts`의 `similarity()` | 임베딩 API. 외부 AI에는 시간표 원본 대신 관심사 텍스트만 전달 |
| `lib/ai.ts`의 `icebreaker()` | LLM API. 모임당 한 번만 호출 |
| 채팅 `send()`와 자동 답장 | WebSocket(STOMP). 자동 답장은 삭제 |
| 긴급 신고 접수 | 운영자 대시보드. 보관 기간과 처리 기준은 출시 전 법률 검토로 확정 |

## 알려진 제한

- 이미지로 시간표 불러오기, 이의 제기, 악의적 평가 신고 같은 확장 기능은 버튼만 두고 비활성입니다.
- 요일은 월~금, 시간은 09:00~21:00만 지원합니다.
- 폰트는 Pretendard를 CDN에서 불러옵니다. 오프라인이면 시스템 글꼴로 대체됩니다.
- 신고와 평가는 이 앱 안에서만 저장되며 서버로 전송되지 않습니다.
